## Сканер штрих‑кодов для станков (Android, внутреннее использование)

Небольшое Android‑приложение на Jetpack Compose для сканирования штрих‑кодов (ZXing)
и проверки «пары» устройств. Сначала сканируем инициализацию (op '1'), затем выполняем
проверки для `device1` (op '2') и `device2` (op '3'). Цвет фона и звук подсказывают результат.

### Формат штрих‑кода
- 13 символов (EAN‑13).
- Структура: `2` + код операции (`1` / `2` / `3`) + код устройства‑1 (3 цифры) + код устройства‑2 (7 цифр) + контрольная.
- Приложение использует позиции для извлечения `device1`/`device2`, проверяет длину и первый символ.

### Логика работы
- Код `1`: приложение запоминает оба станка (`device1` и `device2`). Фон — голубой.
- Код `2`: сверка нового `device1` с сохранённым. Совпадение — зелёный экран + `ok`‑звук, иначе — красный + `bad`‑звук.
- Код `3`: аналогично для `device2`.
- Кнопка «Старт» очищает состояние; «Финиш» — закрывает экран.

### Сигналы интерфейса
- Успех: зелёный фон + `beep_ok.wav`.
- Ошибка: красный фон + `beep_bad.wav`.
- Экран держится постоянно, сканер — в непрерывном режиме (continuous scan).

### Технологии
- Kotlin 2.0
- Jetpack Compose (Material 3)
- ZXing‑Android‑Embedded
- Hilt
- Coroutines / Flow
- Gradle 8.13

### Практическая польза
- Убирает человеческий фактор при выборе станка и снижает риск пересортировки до нуля.
- Ускоряет запуск партии примерно вдвое.
- Не требует авторизации и подключения к интернету.

### Как запустить
- Откройте проект в Android Studio, дождитесь Gradle Sync.
- Нажмите Run для конфигурации `app` (при первом запуске разрешите доступ к камере).
- Наведите камеру на штрих‑код нужного формата.

### Ключевые файлы
- `app/src/main/java/com/example/barcodeapp/ui/MainActivity.kt` — экран, цвета, кнопки, звуки.
- `app/src/main/java/com/example/barcodeapp/ui/BarcodeScanner.kt` — обёртка над ZXing для Compose.
- `app/src/main/java/com/example/barcodeapp/ui/MainViewModel.kt` — логика, состояние, выбор цвета/звука.
- `app/src/main/java/com/example/barcodeapp/domain/Barcode.kt` — парсер строки в `ParsedBarcode`.
- `app/src/main/java/com/example/barcodeapp/BarcodeApp.kt` — точка входа Hilt (DI).
